# 作業再開

1. `~/.kiro/memory/` の索引(自動読込済み)で、進行中の作業(type: project)を確認する。
2. `@@WORK_LOG_DIR@@/` の直近ログを読む。
3. `git status` と `git log --oneline -10` で作業ツリーの状態を確認する。
4. 残タスクを列挙し、`task` ツールでタスクリストに落とす。

洗い出した残タスクは、着手前にユーザーに見せて優先順位を確認する。
