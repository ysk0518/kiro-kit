# 記憶する

## 手順

1. `~/.kiro/bin/kiro-memory list` で既存の記憶を確認する。
2. 同じ話題の記憶があれば**そのslugを更新**する(新規作成しない)。
3. 記憶の種類を決める: `user` / `feedback` / `project` / `reference`
4. 書き込む:

```bash
cat <<'BODY' | ~/.kiro/bin/kiro-memory add <slug> <type> '<1行サマリ>'
何が起きたか・なぜそうなるか。

**なぜ:** 理由(feedback / project のとき必須)
**どう使うか:** 次に同じ状況でどう振る舞うか

関連: [[別のslug]]
BODY
```

5. 索引は自動再生成される。`00-memory-index.md` を手で編集しない。

## 書くときの判断

- 「コードを読めば分かること」は書かない。構造や関数名ではなく、
  **コードに書いていない事情**(なぜその選択をしたか、何を踏んだか)を書く。
- 相対日付は絶対日付に直す。
- 1ファイル1事実。複数の話題を混ぜない。混ざりそうなら分けて2回 add する。

## 記憶が間違っていたと分かったら

`~/.kiro/bin/kiro-memory rm <slug>` で消す。古い記憶を残したまま新しい記憶を足さない。
