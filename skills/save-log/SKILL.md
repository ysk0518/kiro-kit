# 作業ログを残す

1. このセッションでやったことを振り返る。**結果だけでなく過程と手戻りも書く**
   (何を試して駄目だったか、なぜその方針に変えたか)。
2. `@@WORK_LOG_DIR@@/日付_作業内容.md` に書き出す。
   日付は `YYYYMMDD` 形式。
3. ログを書いたあと、**次のセッションでも必要な事実がなかったか**を確認する。
   あれば `remember` skill で `~/.kiro/memory/` にも残す。
   作業ログは経緯の記録、memory は次回すぐ効く索引 — 役割が違うので両方書く。
