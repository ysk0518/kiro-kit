# 思い出す

索引(`00-memory-index.md`)は毎セッション自動で読み込まれている。それ以上が要るときの手順:

1. **記憶の本文** — 索引で当たりをつけて `~/.kiro/memory/<slug>.md` を read。
   slug が分からなければ `knowledge` ツールで「記憶」KB を意味検索する。
2. **作業ログ** — `@@WORK_LOG_DIR@@/` の直近ファイルを新しい順に読む。
3. **設計・仕様** — agent に登録された knowledge base を検索する。
   どの KB があるかは `/context` または `/config` で確認できる。
4. **直近の変更** — `git log --oneline -20` と `git status`。

## 注意

記憶は書かれた時点の事実。ファイルパス・フラグ・手順に言及していたら、
**今も有効か確認してから**それを前提に動く。食い違っていたら記憶を更新する(`remember` skill)。
